# Sean dual-character reference v1

owner: Sean

This package standardizes the already generated H3/Krea reference results for the two roles used by the Continuum dialogue test. It keeps each character independent and records the current coverage gap for Character B.

Canonical inputs:

- Character A: `sean_t2_a_identity_front.png`; optional same-object face and board aids are listed in `manifest.json`.
- Character B: `sean_t2_b_identity.png`; no board or separate face asset is promoted to canonical status.
- Scene, spell, and prop remain separate semantic packages.

The pair board and total board are deliberately not included as default references. The package is ready for ordinary two-person medium shots and the existing 4×8 Continuum baseline. A Character B face close-up and a clean 16:9 observatory source remain targeted additions, not placeholders.
