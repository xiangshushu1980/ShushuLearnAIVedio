# Qwen-Image-2.1 单人服装、武器、场景与体型控制

> Owner: Sean

## 目的

回到单人物生成。固定一名黑发女剑士的脸部身份、制服、武器和月夜庭院参考，只改变提示词里的体型轮廓，判断自然语言能否清楚控制体型，同时不破坏单人构图、服装、刀和场景。

## 三种体型条件

1. **纤瘦**：窄肩窄胯、四肢纤细、修长轮廓。
2. **运动型**：中等偏宽肩、腰部结实、前臂和大腿有肌肉线条，不臃肿。
3. **结实强壮**：宽肩、厚实躯干、粗壮前臂和肌肉大腿/小腿，紧凑有力量感。

每种使用 seed 6200511 和 6200512。参考图、姿势、镜头、场景、服装和武器描述固定。制服参考本身展示了无头全身服装模型，因此也可能带入默认身材轮廓；QC 会将它记作本测试的限制。

结果见 [QC.md](QC.md) 与按 seed 对齐的对照拼图 `outputs/body_type_comparison_seed_aligned.png`。

## 结果

六张图已完成。两颗 seed 下，纤瘦、运动型和结实强壮三种轮廓都能看出差异，结实强壮型最明显；身份、制服的大结构、单把刀、庭院元素和手绘奇幻风格基本保住。镜头距离、正侧角度、刀的位置与制服细节仍会变化，提示词没有锁住这些结构。逐图记录在 QC.md，实验状态为 `review`。
