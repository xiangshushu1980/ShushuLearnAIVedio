# Qwen-Image-2.1 头身比与身高文字控制

> Owner: Sean

## 目的

不加入全身比例图，只使用两张头肩身份图和同款制服参考，比较三类短提示词：

1. 左 8 头身、右 9 头身，两人同高（均 170 cm）；
2. 两人均 9 头身，身高不同（左 160 cm、右 180 cm）；
3. 左 8 头身/160 cm，右 9 头身/180 cm。

每组使用相同的两个 seed。身份、制服、模型和画布设置固定，手部可见，不加武器或配饰。

## 结果

逐图判断见 [QC.md](QC.md)，三组对照拼图见 `outputs/proportion_height_comparison.png`。目标是判断文字约束能否在没有比例图的情况下控制头身比和相对身高；身高厘米数是模型提示，不代表可从画面准确测量真实身高。

本轮目视结果：文字对相对身高差的控制比对具体头身比更明显；两人同高时，指定一人八头身、另一人九头身，没有稳定地产生清楚的头部比例差。第三组能看出两人一高一矮，但不能据此确认模型精确遵循了两项数值。实验状态：`review`。
