# Qwen-Image-2.1 双人统一服装与武器对照

> Owner: Sean

本实验复用 [Krea2 同款制服与武器测试](../krea2_shared_costume_weapon_20261002/README.md) 的两张脸部 crop、Krea2 生成的单独制服和武器参考图、提示词意图及 seed，检验 Qwen-Image-2.1 是否更能让两个人穿同款制服、各拿一把同款武器。

四种条件各两个 seed：仅两张脸；加制服参考；加武器参考；制服和武器参考都加。Qwen-Image-2.1 使用本地基线 int8_convrot、Qwen3-VL 8B、25 steps、CFG 1、Euler/simple。构图提示要求横向 3:2、全身双人同框（当前编码节点实际输出 1024×1024）。主条件共 8 张；另外对制服+武器参考条件做了两个“每人只佩戴一把完整入鞘武士刀”的 prompt 修订样本，共 10 张。

QC 中逐图记录人数、两张脸的区分、制服一致程度、武器款式/数量和画面完整性。与 Krea2 的横向比较仅针对这次固定装备需求，不代表两模型的全面画质排名。

## 当前结论

Qwen 在加入制服参考后，两个角色的制服能够高度一致；Krea2 对照没有做到。第一版加武器参考时，剑柄/剑鞘结构会重复。追加对照发现：**保留两张脸和制服参考，去掉武器图，只在提示词中将刀定义为一把完整入鞘、挂在左腰的武士刀，两个 seed 都成功做到一人一把**。若加武器参考，重复风险上升（追加两张中一张重复）。当前更稳的条件是“脸参考 + 制服参考 + 精确的正向武器描述”，而不是把独立武器图也塞入多参考。详见 QC 的 Follow-up。
