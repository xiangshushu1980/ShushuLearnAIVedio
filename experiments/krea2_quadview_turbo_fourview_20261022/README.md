# Krea2 Turbo QuadView 四视图正面留空试跑

基于官方 QuadView UI workflow 的本机 Turbo 版本。默认提示词沿用官方触发句，只追加按 panel 指定的 face rule；角色描述只列角色特点和签名物品，不重复布局指令。

首轮 face rule 将空脸扩散到特写；prompt v2 明确第 1/2/3 栏之后，3/3 面部栏符合预期。配件仍有失败（法师法杖缺失、矮人工程师背部包不稳定）。详情见 [REPORT.md](REPORT.md) 和 [QC.md](QC.md)。

本实验只验证静态视图板的面部提示词控制，不是 H3 canonical reference 验收。
