# Krea 2 单人物多参考角色一致性实验

> Owner: Sean。实验过程与结果只归档在本目录；未通过目视复核前不视为定论或正式角色资产。

## 目标

固定一名剑士、同一组文字描述、Krea2 Reference LoRA、画幅、采样参数和两个 seed，比较脸部、服装、装备、场景参考各自及组合对输出的影响。特别记录人物身份/衣着漂移和背景结构漂移。

## 对照条件

1. 脸部参考：基准条件。
2. 脸 + 服装裁切。
3. 脸 + 武器装备裁切。
4. 脸 + 场景图。
5. 脸 + 服装 + 装备 + 场景。

所有角色参考沿用同一锚图的绘制风格；场景图来自上一轮 Krea2 + Jibs 辅助生成。输出统一 1024×1024、8 steps、CFG 1、`er_sde/simple`，每条件两个固定 seed。裁切坐标、参数、逐图 prompt 与 ComfyUI prompt ID 记入 `manifest.json`，API 工作流保存到 `api_workflows/`。

## 评估

- 人脸和发型是否保持同一角色；头身比例、姿势允许变化。
- 象牙白上衣、深海军蓝分片外套、红色内衬/腰带、黑色护肩、黑裤与靴子是否稳定。
- 单把武士刀是否保留，颜色、刀鞘/刀柄/弧度是否一致；是否重复或变形。
- 拱门、石路、红叶、冷月光等场景元素是否出现；结构布局是否仍大幅改写。
- 全参考条件是否有额外拼板/参考图复刻伪影。
- 每张图风格是否维持统一的手绘奇幻游戏概念图质感。

## 结果

共生成 20 张并目视复核，逐条件观察见 `QC.md`，prompt/seed/ComfyUI prompt ID 见 `manifest.json`。普通布局下重复人物和拼板频繁；`layout_split=0.25` 让单脸和脸+服装条件各 2/2 保持一个主体，全四参考仍 0/2 干净。场景图稳定传入石拱、红叶和夜色，但空间布局仍重组。服装/装备参考从同一全身锚图裁出，残留相邻上下文；结论只适用于本轮样本，不是通用定论。外部官方与社区评价见 `SOURCES.md`。
