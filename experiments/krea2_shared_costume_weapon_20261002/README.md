# Krea2 双人统一服装与武器测试

> Owner: Sean

## 目的

验证同一画面中两张不同人物脸部参考，能否和提示词或共享服装/武器参考配合，让两个人穿同款制服、各拿一把同款武器，并维持同一画风。

## 条件

每种条件使用两个固定 seed：

1. 两张脸参考，仅用提示词约束制服和武器。
2. 两张脸 + 单独制服参考。
3. 两张脸 + 单独武器参考。
4. 两张脸 + 制服 + 武器参考。

两张脸取自 2026-09-28 Krea2 角色锚点，不含 Shushu 照片。服装和武器参考图由 Krea2 文生图生成，不纳入得分；主测试共 8 张。统一用 `layout_split=0.25`、8 steps、CFG 1、`er_sde/simple`、1280×832 和相同画风提示。

## 判定方式

逐张查看：是否恰为两人；两张脸是否仍可区分；制服的颜色、剪裁和关键部件是否在两人身上对应；两把武器的轮廓与细节是否一致；是否保持一个连续画面和同一画风。每条件只有两个 seed，结果用于判断可行性，不代表统计稳定性。

逐张结论补充在 `QC.md`。生成工作流、prompt、参考图和图像保存在本目录，manifest 记录运行参数与结果。

## 当前结论

8 张主图已完成。两张不同脸在前六张中仍能区分，但两人原本的角色服装特征持续残留，制服参考也没有统一肩甲、剪裁和整体轮廓。武器参考能让刀型更接近，但重复武器问题仍在。制服+武器+两张脸共四张参考时，两个 seed 都生成额外的漂浮服装/人物结构。逐张证据和限制见 [QC.md](QC.md)。
