# 故事创作边界 v1

> 本文件是 `wow-mage-survival` 的讨论约束，不是 ComfyUI 工具规范，也不是正式剧本。

## 核心原则

### 1. 只借用任务结构，不直接使用 WOW 角色

- 故事中永远不出现当前 WOW 的著名 NPC。
- 故事中也不直接使用当前 WOW 的非著名 NPC。
- Classic Era 任务资料里的 NPC 名称只作为研究索引，不能直接进入剧本、对白、字幕、角色提示词或最终画面。
- 所有任务发布者、士兵、农民、矿工、盗贼、牧师和其他角色都必须重新设计中文名字、经历、外貌和行为动机。

### 2. 只借用世界功能，不直接复制标志性视觉

- WOW 的地点、任务关系和生态功能可以作为结构参考。
- 标志性建筑、屋顶颜色、旗帜、徽记、制服、城市轮廓和装饰语言必须重新设计。
- 例如：人类城镇不直接使用暴风城式蓝色屋顶；可改为黄色屋顶，并重新设计城墙、木构件、徽记和公共空间。
- 血精灵相关城市不直接复刻原作红金色视觉；可以发展为蓝色主导的城市，但具体色阶、材质、光源和建筑语法另行讨论。
- “像 WOW 的功能”和“看起来就是 WOW 的复制品”必须分开记录。

### 3. 视觉参考的使用方式

- 参考图用于提炼材质、比例、构图、服装层级、建筑功能和光影逻辑。
- 不以复刻某个官方角色、建筑或截图为生成目标。
- 后续生成提示词必须优先使用我们自己的中文名称、地理名称、颜色体系和造型规则。
- 参考资料进入候选集前，先标记为：`结构参考`、`材质参考`、`动作参考` 或 `风格参考`。

## 第一阶段执行边界

北郡只保留 Classic Era 的任务骨架、地理关系和低等级生存压力。下一步为每个任务建立新的中文版本：

| 原任务功能 | 新设计要求 |
|---|---|
| 修道院接到第一个任务 | 使用原创修道院、原创基层联络人和原创新手身份登记流程 |
| 猎狼 | 狼群、伤口、血迹、地形和逃生路线保留；任务发布者和村民全部换名 |
| 矿洞清理 | 保留矿洞生态与狭窄地形；矿工、狗头人对应族群、工具和任务物件重新设计 |
| 葡萄园失窃 | 保留边境农庄的物流冲突；葡萄园布局、酒桶、农户和盗窃者重新设计 |
| 盗匪追捕 | 保留“第一次面对有组织人类敌人”的功能；组织名称、面巾、武器和标志全部原创 |
| 前往下一个聚落 | 保留离开出生地的生存转折；聚落名称、城镇色彩和道路标志重新设计 |

## 当前阶段的下一步

先完成 `northshire_v1.md` 的“任务事实表”，字段为：

1. Classic 任务功能索引；
2. 我们的新中文任务名；
3. 原创 NPC / 敌人 / 地点名称；
4. 普通人视角下的真实危险；
5. 火、冰、土可以介入的物理问题；
6. 失败、撤退和受伤后的后果。

在这张表完成前，不开始大规模 ArtStation 下载，也不把任何 WOW NPC 名称写入生成提示词。
