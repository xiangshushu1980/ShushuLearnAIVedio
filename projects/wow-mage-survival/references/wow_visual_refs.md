# WoW 视觉校准参考（T-comfy-ops-37）

这些链接只用于提炼视觉特征，不作为最终素材直接使用。

> 本文件已经按 `wow-mage-survival` 的原创边界解释：WOW 资料只能提供空间功能、材质线索和任务语境。原作 NPC、旗帜、徽记、服装识别物和标志性配色不得直接进入最终设定图。

## 本批筛选方式

本轮暂不下载图片。先人工确认每张图的可借鉴点，再分为：

1. `结构`：建筑、道路、空间关系；
2. `材质`：木、石、布、金属、火焰、冰晶；
3. `氛围`：时间、天气、色温、危险感；
4. `法术逻辑`：元素如何成形，以及怎样改变地面、遮挡、移动和攻击。

## 生成约束

- 目标是 WoW Classic-inspired 的 stylized 3D game art，不是写实中世纪电影剧照。
- 普通农民也穿合身、染色、耐用且有层次的衣物；贫困和破败主要通过环境表达。
- 人类城镇：浅色石墙、黄色屋顶候选、重新设计的旗帜和徽记、厚重城门；不得直接复制暴风城蓝色屋顶体系。
- 西部荒野：黄褐草地、农场、风车、木栅栏、宽阔地平线、被战争掏空的边境。
- 死亡矿井：狭窄矿道、木支撑、铁轨、木板平台、火把、潮湿岩石和海盗/工匠工业感。
- 原创盗匪：保留成组巡逻、轻型护具、短刀/弩等功能；面巾颜色、徽记、服装语言和组织名称全部重新设计。
- 火冰魔法可以夸张，但人物、建筑和装备必须保留游戏化块面、清晰轮廓和鲜明色块。
