## 接下来验证的交互职责

- 用户决定图片是否作为实体设计或主图；Agent 提供建议，不能自动推翻人工选图。
- Agent 共用项目上下文，通过受限工具读取资料、观察图片、提案实体/关系/空间与工作流；生成由应用执行器按授权提交。
- 应用校验引用、修订和来源，持久化结果；界面需要让用户看见提案、差异、报告与图片，并调整或接受。
- 空间确认单独进行，未知的信息保持待补充。主图选择、应用文字提案、空间确认三个动作不能混同。
- 图片一致性是创作结果的检查项，取景未实现也是工作流执行反馈；不以无限修图替代自然语言创作闭环验证。
