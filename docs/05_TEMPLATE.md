# 05 会话交接 — 模板（activeContext 结构）

> 用法：新会话开始时，复制本模板为 `docs/05_session_handoff.md` 并填充；上个会话的 05 归档到 git 历史即可。
> 本文件是新会话恢复上下文的**确定性入口**：AGENTS.md 开场流程强制先读它（INDEX → 05 → memory_recall）。
> 核心假设：每个新会话都是"失忆"的——本文件必须让下一个 agent 不看聊天记录就能无缝继续。
> 对齐 Cline Memory Bank 的 activeContext.md（当前焦点/最近变更/活跃决策/模式偏好/下一步）。
