## 首帧锚定规律（本次核心发现，解释全部历史数据）

**first_frame 锚定强度取决于 首帧图 与 prompt 场景 的一致性**：

| 首帧图 vs prompt 场景 | SSIM | 案例 |
|---|---|---|
| 场景一致（图=海边，prompt=海边） | 0.99 | A2/E1/F1/F4 |
| **场景冲突（图=海边，prompt=舞台）** | **~0（模型重绘首帧）** | F3 原始 |
| 生成帧（OOD） | 0.14-0.52 | C2/C3/C4 |
| 场景匹配（图=舞台暗场，prompt=舞台） | **0.993/0.996** | F3b 修正 |

机制：场景冲突时模型为匹配 prompt 场景重绘首帧（F3 首帧亮度 36 vs 输入 188；尾帧 4.8 落幕全黑）。
不是光照覆盖——归一化结构 SSIM 仍 -0.086（结构也变了）。
