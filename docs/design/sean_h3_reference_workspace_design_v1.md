## 页面关系与入口

用户进入产品后先到“工作台总览”。主操作是“创建参考实体”；已有实体以最近活动卡片呈现，提供“继续编辑”。创建后进入该实体的创建/编辑会话；也可从实体卡片再次进入。总览只负责开始与续接，不呈现通用媒体库、角色/场景/道具分类、工作流浏览或节点编辑入口。

会话内左侧按依赖呈现五个创作面板：设定收集、概念图、主形象、三视图、声音。概念图与主形象属于“主形象确认”这段视觉流程，但在此拆为两个清晰步骤，避免用户误以为是一次生成。三视图等待已确认主形象；声音可以独立开始。步骤状态同时表达锁定原因、生成进度和确认情况。

## 五面板契约

| 面板 | 页面内容 | 关键边界 |
|---|---|---|
| 设定收集 | 实体介绍、已收集设定资料、派生/编辑的提示词版本、保存状态 | “添加资料”只在此出现；保存资料不触发生图 |
| 概念图 | 一张必选主参考、一张可选第二参考、提示词、风格设置、多个候选 | 只把明确选中的最多两张图送入 Krea2 Edit；生成后候选等待审核 |
| 主形象 | 已确认概念图、主形象提示词与风格、候选预览 | 概念图确认后可启动；更换概念图会令旧主形象显示“待更新” |
| 三视图 | 已确认主形象、固定三视图生成、合成图预览 | 前置主形象未确认时不可启动；一个合成图作为单个结果确认 |
| 声音 | 提示词或音源与准确转写、系统提供的试听台词、多段候选试听 | 与视觉流程并行；BGM 不在本阶段 |

右侧各面板统一采用“输入与参数 → 运行状态/进度 → 输出预览 → 确认/恢复 → 可选 ComfyUI 详情”的顺序。只要新运行尚未确认，原确认版本仍是当前版本。ComfyUI 入口从当前 run 打开；只有能定位同次运行时才显示为运行详情。日常生成、进度查看和结果审核留在 Reference 工作台完成。

| 既有内容 | 决定 | 理由 |
|---|---|---|
| 设定收集、概念图、主形象、三视图、声音的工作区分区 | 复用并整理为五个清晰步骤 | 与已验收架构和创建/编辑流程一致 |
| 各右侧面板的参数、进度、输出和审核结构 | 复用其稳定位置与交互 | 保持步骤间操作习惯一致，并支持候选确认/恢复 |
| 概念图面板左右对照输入与候选预览 | 复用信息结构 | 能直接比较当前确认版和正在生成/待审候选 |
| v1/v2/v3 总览中的顶部“素材库、灵感参考、角色、场景、道具、音频、工作流” | 删除，改为“工作台总览、最近活动、模板与帮助” | 旧导航把 Reference 创作混入通用资源分类；模板入口也不应变成运行时编辑工作流 |
| “参考资料/角色”作为产品主名 | 改为中性的“Reference 工作台”工作标题 | 产品名称尚未确定，不预设为 Media Browser，也不把 comfyui-browser 误作新应用名称 |
| 全局“添加资料”按钮 | 限定到设定收集面板 | 资料添加是创建阶段的一部分，其他面板只选择已经登记的资料 |
| 通用素材库的卡片、分类和浏览操作 | 不纳入本产品导航 | 普通媒体资源由 `comfyui-browser` 插件独立浏览；Reference 工作台只显示当前实体已登记的参考资料 |

## 评审重点

1. 总览是否让“新建实体”和“继续编辑”一眼可见，并准确表达 Reference 工作台用途。
2. 用户是否能理解概念图、主形象是两个先后审核的生成步骤，三视图依赖主形象，声音可并行。
3. 五个面板统一位置后，生成中、待审核、已确认和恢复操作是否足够清楚。
4. “可选 ComfyUI 运行详情”措辞只用于已验证能定位同次运行的入口；否则先隐藏该按钮或改成准确的能力描述。
5. 产品名、实体类型标记与状态颜色仍可在产品评审中调整；本稿不冻结命名或完整实体分类。
