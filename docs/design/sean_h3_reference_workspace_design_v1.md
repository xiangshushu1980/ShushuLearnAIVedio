## 页面关系与入口

本稿不设计创建入口、管理页或浏览页。用户从后续管理/浏览界面选定一个具体实体后进入该实体的创建/编辑会话；实体介绍和关系图谱在浏览/管理界面维护，创作会话只使用 Agent 可访问的实体上下文，不在此编辑实体信息。本稿只呈现选中实体的创作步骤和面板，不预设上游如何查找或选择实体。

会话内左侧按依赖呈现五个创作面板：设定图片、概念图、主形象、三视图、声音。概念图与主形象属于“主形象确认”这段视觉流程，但在此拆为两个清晰步骤，避免用户误以为是一次生成。三视图等待已确认主形象；声音可以独立开始。步骤状态同时表达锁定原因、生成进度和确认情况。

## 五面板契约

| 面板 | 页面内容 | 关键边界 |
|---|---|---|
| 设定图片 | 当前目录中选择并导入的图片 | 操作只包含图片多选与导入；不在此编辑实体介绍、关系、备注或提示词，也不生图。图片说明和来源信息由后续流程维护，不增加导入前的填写步骤 |
| 概念图 | 设定图片、概念图历史、提示词和风格设置；设定图与形象探索图片的生成阶段，用于探索/试验，可多轮生成 | 每次运行可从设定图片和历次概念图结果中明确选择多张引用；历史结果直接复用，不必导入设定图片；提示词与引用方式依模型能力配置；保留历次试验结果。当前主形象引用的概念图受保护；进入历史的结果自动锁定，提供显式锁定/解锁，解锁后可删除；曾定稿项保留标记；当前测试方向为 Qwen Image 2.1，用户反馈其引用表现可用，Krea2 参考图一致性较差 |
| 主形象 | 从概念图试验结果中选择一张作为最终定稿 | 这是选择和定稿，不另起一次生图；定稿后作为三视图等后续步骤的主视觉输入，并保持为独立版本，不随概念图区后续试验自动改变 |
| 三视图 | 已确认主形象、固定三视图生成、合成图预览 | 前置主形象未确认时不可启动；一个合成图作为单个结果确认 |
| 声音 | 提示词或音源与准确转写、系统提供的试听台词、多段候选试听 | 与视觉流程并行；自动转写须经用户校对确认后才能作为生成输入；用户明确选择试听通过的样音并定稿为当前声音 Reference；当前版受保护，换版后旧版进入自动锁定的历史，可解锁后删除；BGM 不在本阶段 |

### 资源备注与来源信息

所有 Reference 资源的信息服务两类使用者：人需要快速理解资源是什么、为何保留、适合怎么用；下游工作流和 Agent 需要准确、可查询、可追溯的结构化上下文。UI 信息分成两部分：可留空且可由用户编辑的人类可读说明，以及程序维护的机器上下文；手动说明留空不阻止资源加入或定稿，自动信息不覆盖手写说明。

当前生效的定稿资源受保护；换版后旧版进入历史并自动锁定，提供显式解锁后删除的路径。概念图保留是否曾被定稿的历史标记；声音沿用同一锁定/解锁行为。

### 实体信息的界面边界

实体介绍和实体关系（关系类型 + 自由描述）在浏览/管理界面维护；关系图谱、固定当前关系及未来剧情时间维度属于该界面的设计范围，不放进本次创建/编辑面板。创作会话只读取选中实体可供 Agent 使用的上下文。当前创作 UI 保持五步生成流程简洁。

机器上下文优先保存稳定字段和引用关系，而非把技术事实抄成备注文字。生成资源建议关联资产 ID/类型、实体与用途、来源步骤、run、模型/工作流版本、提示词版本、实际输入素材 ID 和生成时间。若 ComfyUI 输出嵌有 prompt/workflow 元数据，导入时保留原始文件并提取可识别信息；未嵌入、被剥离或无法解析时，以工作台自己的运行记录为准，不凭空补造。ComfyUI SaveImage 在启用元数据时可把 `prompt` 与 `extra_pnginfo` 写入 PNG；具体字段会受保存节点、文件格式和设置影响。

人类可读说明建议聚焦“内容/用途/生成意图”，而非重复列出原始工作流 JSON 或全部提示词。对工作台生成的资源，可根据步骤目的、用户输入的提示词和本次引用素材形成简短说明；对从目录导入的图片，可由后续视觉能力自动生成画面内容说明；对导入的音频，可由后续音频能力生成音色特征、内容/转写或用途说明，供人和 Agent 使用。人可以编辑说明；人工修改不得被后续自动描述静默覆盖。音频自动转写用于生成前必须由用户校对确认。机器字段和人类说明的精确字段、自动生成时机与编辑方式仍需结合各类资源逐项确认。

概念图、三视图和声音等生成面板统一采用“输入与参数 → 运行状态/进度 → 输出预览 → 本面板的下一步动作 → 可选 ComfyUI 详情”的顺序。设定图片面板保持独立简化：从当前目录多选图片并导入，展示图片，不出现模型、提示词、生成结果或备注编辑控件。概念图结果可选为主形象，声音试听结果由用户挑选后定稿。ComfyUI 入口从当前 run 打开；只有能定位同次运行时才显示为运行详情。日常生成、进度查看和结果审核留在 Reference 工作台完成。

### 操作与状态反馈

保持每个步骤的主要操作清晰、数量克制；生成开始和运行中只显示状态与进度。生成完成或失败时，参考 comfyui-browser 播放短提示音并出现一次短暂屏幕 glow；不在每次进度变化时反复提醒。具体音效、glow 强度和静音控制在后续 UI 评审中定稿。

### 概念图面板：具体使用方式

概念图是引用图片进行生图的试验区，用来探索形象设定与呈现方向。用户可在单次运行中从已收集的设定图片和概念图历史选择多张引用；概念图结果可在后续运行中直接复用，不需要先导入设定图片。用户也可编辑提示词和风格；每轮生成有一个“本轮目的/想验证什么”字段，由 Agent 根据用户要求、实体介绍与关系、已选引用图和目标模型能力草拟目的及本轮提示词，用户审阅或手动修改后再运行。目的、最终提示词及其余输入一起保存，可用于生成人类可读备注。运行后继续调整和多轮试验。稳定的实体介绍/基础提示词可由实体 authoring skill 建立；每轮变化的目的和提示词属于运行准备阶段，未来由用户调用 Agent 时传入本轮上下文，本设计不要求 UI 内嵌或自动调用 skill。每种模型可接受的引用图数量、引用输入方式和提示词组织方式不同；运行表单与提示词辅助应依据所选模型的真实能力配置，在开发阶段确定，不在设计稿中写死数量或结构。历次试验结果保留为可浏览的历史。当前主形象所引用的概念图受保护；其他结果进入历史时自动锁定，提供锁定/解锁操作，解锁后方可删除。若历史图已被后续运行引用，删除前提示其影响；确认删除后移除图片资源，但保留运行记录中的来源标识，并显示“来源图已删除”。曾被定稿的旧结果保留“曾定稿”标记并自动锁定。用户反馈当前测试中 Qwen Image 2.1 的引用能力可用，Krea2 的参考图一致性较差；界面和工作流选择应体现这一反馈，不再默认以 Krea2 Edit 作为概念图生成路径。未明确选择的图片不会自动混入本次运行。

提示词从实体介绍等 Agent 可用上下文中建立，用户可补充这次希望呈现的目的/情境并保存新提示词版本。设定图与形象探索所需的图片生成统一在概念图试验区完成；若为其他设定用途生成，也在此说明本轮目的，不在设定图片面板增加第二套生成入口。三视图与声音仍按各自步骤生成。所选模型的能力决定引用图和提示词如何组织；实现时应让模型配置提供相应输入契约和提示词辅助。每次运行保留实际使用的图片及版本、目的、提示词版本和模型/模板配置版本，结果进入试验历史；后续运行可直接选择设定图片或概念图历史中的图片；用户可从某个结果明确选择主形象定稿。

概念图试验结果不会自动成为最终主形象。用户在主形象步骤中从概念图结果里选择一张并定稿；定稿成为独立主形象版本，概念图区后续试验不会自动替换它，只有用户再次明确选择并定稿才会改变。后续三视图以定稿主形象为输入。主形象步骤不再重复生成概念图中已经完成的图片生成。

主形象面板展示概念图候选历史、当前选择的大图和当前主形象版本。用户选择候选并执行“设为当前主形象”后，生成一条独立主形象版本；定稿保留所选概念图及对应运行信息。替换时旧主形象进入自动锁定的历史。作为当前主形象来源的概念图受保护；已被后续运行引用的历史概念图在解锁删除前显示影响提醒，删除后相关运行仍保留来源记录并标记“来源图已删除”。

### 实体介绍与提示词的 Agent 边界

实体介绍在浏览/管理界面由 Agent 协助建立并由用户手动修改；创作会话不编辑实体介绍。每次生图准备时，用户通过 Agent 提供本轮上下文，由 Agent 生成目的和适配提示词；用户可在步骤面板检查、修改和保存本轮文本。是否提供应用内 Agent 按钮、使用何种 Agent/API 或接入 Pi/Codex，留到后续实现方案确认，本轮不嵌入 Pi/Codex 会话或 CLI。

### 风格配置

概念图以选择已保存的风格配置为主路径，并可在试验过程中切换已保存风格。主形象从概念图结果中定稿，因此继承被选结果本身的风格，不再单独启动一个主形象生成运行。当前界面不展开单项 LoRA 权重、风格参考图或风格提示词等底层参数。

## 评审重点

1. 用户从后续管理/浏览界面选中实体进入创建/编辑时，当前实体是否足够明确。
2. 用户是否能理解概念图是试验区、主形象从试验结果中选择定稿，三视图依赖主形象，声音可并行。
3. 五个面板统一位置后，生成中、待审核、已确认和恢复操作是否足够清楚。
4. “可选 ComfyUI 运行详情”措辞只用于已验证能定位同次运行的入口；否则先隐藏该按钮或改成准确的能力描述。
5. 产品名、实体类型标记与状态颜色仍可在产品评审中调整；本稿不冻结命名或完整实体分类。
