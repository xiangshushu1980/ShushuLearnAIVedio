# 临时小说实验：《潮汐站的钥匙》v0.1

> Owner: Sean。2026-10-07。为实体画布验收编写的虚构短文草案；非生产设定。一个项目、两章、每章一个剧情场景。不包含视频或拍摄本。sourceRevision=1；下列段落ID为来源锚点建议，不是应用内已分配ID。

## 项目共同基准

近未来的海边旧城。故事发生在同一座退役潮汐观测站，人物与物件保持朴素、实用的外观。项目视觉风格暂定电影感写实；这是实验设计选择，非小说推断。

## 第一章：交接

场景：傍晚，旧潮汐观测站的值班室。

**C1-P1**：林乔推开值班室的木门。她三十岁，黑色短发齐耳，穿深蓝色工作夹克，左袖口有一小块方形补丁。海风吹动窗边的纸张，她伸手压住它们，露出没有伤口的右手。

**C1-P2**：周衡坐在桌旁。他四十二岁，头发短而灰白，穿褐色帆布外套。两人曾在这座站共事三年；离职以后，这是他们第一次见面。他把一把铜钥匙放在桌上，没有立即推给林乔。

**C1-P3**：值班室北墙是一面旧仪表盘，东墙有一扇窄窗，向南的木门通往走廊。铜钥匙约一个手掌长，圆形钥匙头中央有三道刻痕，开启的是值班室西侧的档案柜。

**C1-P4**：“天亮前把旧记录带走。”周衡说。他重新收起铜钥匙，放进口袋。林乔点了点头。她不知道周衡为何选在这一天回来。

## 第二章：归还

场景：次日清晨，同一间值班室。

**C2-P1**：林乔从南门进来，深蓝色工作夹克外罩着一件铁锈红色雨披。她右手背有一道新鲜擦伤，是刚才走廊里倾倒的工具架划的；她仍能活动手指。她的短发被雨打湿了。

**C2-P2**：周衡仍穿着昨晚的褐色帆布外套。他站在西侧档案柜旁，把铜钥匙交到林乔左手中。钥匙上的三道刻痕没有变化。林乔打开柜门，把一叠旧记录装进自己的包里。

**C2-P3**：周衡退到北墙仪表盘前，让出通往南门的路。“现在归你保管。”他说。林乔把钥匙收进夹克左口袋，雨披遮住了袖口的方形补丁。东窗外的光慢慢亮了。

## 画面实验指令（来自用户实验目标，非小说原文）

目标为林乔的全局基准形象：齐耳黑短发、深蓝工作夹克、左袖方补丁，无雨披与擦伤。第一轮人物概念图采用中性灰背景；第二轮明确引用第一轮候选，将背景改为纯白，并保留人物、服装和构图。两轮seed及提示词由实际输入记录固定，不预设生成必然成功。

检查第二章状态不会改变全局基准衣着和第一章无伤状态；第一章钥匙归周衡、第二章末归林乔。人物事实、持有关系和本场穿着分别记录。小说原文不因采用外观设计被改写。
