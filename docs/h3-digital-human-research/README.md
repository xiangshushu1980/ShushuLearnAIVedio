## 总体认知

H3 是联合音视频生成模型，画面、人物动作、镜头和声音可以在同一生成状态中协同产生。当前研究目标不是泛泛验证“能否做数字人”，而是验证：在粤语顶级 TTS 音频驱动下，通过 MC（Motion Context）连续续接、细节参考图、latent 放大和必要时的全精度分片，H3 是否能在最终成片质量上超过 InfiniteTalk。

对数字人的关键区分是：

```text
H3 原生参考音频：让模型理解/模仿声音与表演
NativeAudioLock：尝试把已有 vocals 固定到 H3 audio latent
```

二者不能混称为“音频驱动”。

本项目的音频基线是外部顶级粤语 TTS。H3 自生成粤语声音、普通话音频结果和商业 API 的“多语言支持”都不能直接替代粤语实测。

当前已有一组“粤语音频 + 对应口播稿”作为 H3 测试基准。该音频是口型、停顿、语速和连续性测试的时间真值；对应稿件只用于语义核对、分段和镜头意图标注，不在测试中重新生成音频。素材实际文件名和路径待接入后登记，不能用新合成音频替代。

比较主线：

```text
同一角色参考图 + 同一粤语 TTS
→ InfiniteTalk I2V/V2V 基线
→ H3 MC 分片
→ H3 MC + 细节参考图
→ H3 MC + latent 放大/全精度分片
```

## 资料结构

```text
官方 H3
 ├─ FL2VA：首帧/尾帧约束的音视频生成
 ├─ Ref2VA：图片/视频/音频参考的音视频生成
 └─ 结构化 prompt：镜头、角色、台词、环境声、音乐

开源扩展
 ├─ NativeAudioLock：外部 vocals 约束
 ├─ FaceRefine：脸部局部精修和身份检查
 ├─ Motion/Context：跨片段状态传递
 └─ LongMedia/Continuum：长视频编排

外部参照
 └─ InfiniteTalk：音频主导 + 稀疏关键帧 + streaming context
```
