# 24 出图质检线上 VL API（2026-08-16 实测定论）

## 背景与定位

- ComfyUI 出图后的客观质检（内容/文字/崩图/比例）不能走本地 LM Studio（与主模型互斥显存调度），故走线上便宜 VL API
- 分工：**客观质检=线上 VL（本文档）**；**主观审美=用户目视**；**听（音频）=本地 whisper**（线上 Omni 不用于听）
- 候选淘汰记录：deepinfra VL 弃（直连不通需代理）；Omni 五段式报告不需要（用户 2026-08-16 拍板）

## 选型结论（2026-08-16 实测）

| 用途 | 模型 | 工具 | 实测结论 |
|---|---|---|---|
| 内容/崩图/比例质检 | `qwen3-vl-flash`（最省档） | vision_chat | PASS/FAIL 双向验证通过，结构化输出 |
| 文字提取 | `qwen3.5-ocr` | ocr | 带字样本提取正确 |
| 视频帧质检 | `qwen3-vl-flash` | vision_chat `videos` 参数 | 帧采样可用（无音频，符合听用本地） |

## 实测矩阵（2026-08-16）

1. **OCR**：text_ctrl3_matrix.png → "MIDNIGHT CAFE" 提取正确（无空间定位能力，只能确认文字是否渲染对）
2. **好图 PASS**：h3_facerefine_T1.png → 全项 PASS 可用（模型描述与图实际吻合：左女角色/右持剑者棋盘格遮挡）
3. **崩图 FAIL**：attn3way_dance.png（6 格 Sol-Attn 对比图）→ 逐格评估，6 格全部检出缺陷（头颈断裂/手指粘连/膝盖外翻/鬼影/穿模/残影），总体"需重跑"——与已知崩坏高度吻合；多格对比图也能正确拆分
4. **视频识别**：h3_batch_b0c001f0.mp4（5.2s，video_max_frames=6）→ 正常返回帧采样结果
5. **写实图**：krea_scene_city.png → PASS（夜景霓虹街景描述吻合）
6. **生图→识别对照**：krea2_t2i 生图 20s → 识别 PASS；⚠️ krea2_t2i_test workflow 实际是动漫系 checkpoint（生成 Q 版狐娘，photorealistic prompt 未生效）——写实人脸样本仍缺（非核心，动漫是成片主线）

## 质检 prompt 模板（vision_chat，text 参数）

```
你是 ComfyUI 出图质检员。请客观检查这张图的以下项目，逐项回答 PASS 或 FAIL 并给一句理由：
1) 脸部质量（五官是否清晰、有无变形/崩坏/多余器官）；
2) 肢体结构（手指/手臂/腿的数量与比例是否正常）；
3) 画面整体比例（人体比例、构图是否正常）；
4) 画面清晰度（有无明显模糊/噪点/伪影）；
5) 有无明显渲染瑕疵（重复纹理、漂浮物体、穿模、鬼影残影）。
如果图中是并排对比图，请分别评估每一格。
最后给一个总体结论：可用 / 需重跑。
```

视频版：把 1)-5) 改为 脸部质量/肢体动作连贯性/画面稳定性/内容一致性/渲染瑕疵，加 video_max_frames（建议 6，≈每秒 1 帧；上限 250 帧）。

## 费用实测（可忽略）

| 场景 | 实测 token | 估算费用 |
|---|---|---|
| 单图质检 | ~1500 tok（图 1026-1100 + 文本 150） | < 0.001 元/张 |
| 6 格大图 | ~4000 tok（图 2462） | ~0.002 元/张 |
| 视频 6 帧 | ~1900 tok（视频 1730） | ~0.001 元/次 |

单价锚点：qwen3-vl-flash 官方约 $0.022/M 输入 + $0.215/M 输出（海外镜像口径，国内百炼更便宜）；每张图成本为万分之几元级。

## 延迟实测

- 每次调用 20-30s（含上传+推理；created 时间戳间隔 21-36s）——对异步质检批处理可接受，不适合交互式实时质检

## 配置与调用

- `~/.qwen-mm-plugins/config`（600 权限）：DASHSCOPE_API_KEY + MaaS 端点；key 不进 git/记忆
- MCP 网关 server `qwen-mm-plugins-api`，工具 `vision_chat`/`ocr`（model 参数显式指定最省档）
- 联测脚本：`scripts/img_qc_test.py`（生图→打印输出路径→vision_chat 识别）

## 边界

- ocr 无空间定位：只能验证"文字是否渲染对"，不能验证"文字在正确位置"（位置控制弱是 H3 已知问题，见 params.md）
- vision_chat 无音频：视频质检只看画面，听走本地 whisper
- 单次 ≤250 items（帧+图），视频很长时先抽帧
