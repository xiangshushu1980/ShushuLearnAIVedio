## 已确认产品边界

- 第一轮代码实现只做“设定图片”和“概念图”两项；主形象、三视图和声音暂不纳入该迭代。
- 工作台按 `docs/49_h3_reference_workspace_architecture.md` 采用独立 React + Vite 8 应用；不要把它放进 `web-shotlist`，也不要扩展 `comfyui-browser`。仓库目前没有 Reference 工作台应用代码。
- 普通媒体浏览仍由 `comfyui-browser` 插件单独承担。
- 设定图片面板只允许从当前目录选择并多选导入图片；没有图片生成、模型选择、提示词、实体介绍/关系编辑或手动备注编辑。所有设定图与形象探索用的图片生成放在概念图阶段；三视图和声音将来仍按各自的生成流程。
- 概念图可在单次运行中引用多张图片，来源既包括设定图片，也包括此前的概念图历史；历史图可直接作为下一轮输入，无需另导入设定图片。未选中的图片不能静默进入运行。每个模型具体支持几张、如何组织引用与提示词，须按工作流能力配置，不在界面中写死。
- 概念图是试验区；提示词和风格试验在此完成。每轮可有选填目的字段。Agent 可基于实体上下文、运行目的、引用图和模型草拟目的/提示词，用户手工复核修改；Agent 在当前阶段由用户外部调用，不内嵌 Pi/Codex 或自动调用 skill。
- 风格以已保存风格配置为主，可临时切换其他已保存风格。
- 当前测试方向：Qwen Image 2.1 的引用表现可用；用户反馈 Krea2 ref 一致性较差。开发时按选定模型能力适配，不能把旧 Krea2 设计当固定前提。
- 概念图历史保留；进入历史时自动锁定，支持明确锁定/解锁。当前用作主形象来源的图受保护；曾被定稿的历史项保留标记。解锁后可以删除。若图被后续运行引用，删除前提醒；确认删除后，相关运行记录保留来源标识并显示“来源图已删除”。
- 生图开始/进行中显示状态与进度；成功或失败时播放一次短提示音并短暂屏幕 glow，不随进度重复触发。图片导入仅使用普通状态反馈，不触发生图音效/glow。
- 每项资源的说明可为空；人类可读说明和机器上下文分开。后续 Agent/程序可补充，自动内容不可静默覆盖人工修改；当前简化导入界面不要求用户填备注。
- 用户明确要求创建/编辑保持简洁；实体介绍和实体关系维护在后续浏览/管理界面，不放进创建步骤。
