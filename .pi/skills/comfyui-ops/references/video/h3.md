# MiniMax H3 视频

H3 是当前项目主力视频能力。普通 Ref2VA 的现行操作参数只读 [生成手册](../../../../../docs/34_ref2va_generation_guide.md)，模型及禁止恢复项读 [模型清单](../../../../../docs/02_models.md)。`docs/09_h3_test_plan.md` 和旧版参数档案是历史证据，不决定当前设备、步数或服务操作。

任何 H3 测试、生成或提示词任务，先读 [h3-prompt-writing/SKILL.md](../../../h3-prompt-writing/SKILL.md) 中对应模式的官方参考，并读 [docs/17_h3_prompt_writing_rules.md](../../../../../docs/17_h3_prompt_writing_rules.md)。

## 常用路线

- FL2VA：首帧图/文本 → 视频。
- Ref2VA：参考图/视频/音频 → 视频与原生音频。
- Motion Context / NativeAudioLock：连续片段和外部音频锁定等专项路线。

节点含义可按需查旧版 [nodes.md](../nodes.md) 的 H3 小节；其中历史性能和操作建议须核对现行手册及结论替代关系；不要将普通 `ref_audio` 与 NativeAudioLock 混用。
