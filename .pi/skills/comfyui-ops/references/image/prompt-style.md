# 统一世界观与风格提示词研究

这是小说视频 AI 设定图研究的入口，不是正式资产生产规范。

## 建议实验分层

```text
全局风格块
→ 世界观/时代/材质块
→ 人物、场景、道具或法术主体块
→ 构图与镜头块
→ 状态变化块
```

每次只改变一个变量，固定模型、尺寸、seed 和采样参数，生成 contact sheet 后比较。

## Object ref 研究对象

- 人物：身份、年龄、衣着、受伤、变身等外观状态。
- 场景：地点、时段、天气、空间气质。
- 道具：类别、材质、新旧、损坏和剧情状态。
- 法术：颜色、形状、材质、光晕和能量阶段。

不改变外观的情绪/动作优先作为提示词变量，不提前生成所有状态组合。
