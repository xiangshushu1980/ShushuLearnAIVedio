## 命名规则（文件名排序 = 浏览顺序）
`{分辨率}_{时长}_{优化}_{步数}.mp4`

排序优先级（字母序天然满足）：
1. **分辨率**（同分辨率相邻，如 768x448 组）
2. **时长**（两位补零：08s → 10s，时间升序）
3. **是否开优化**（`base`=无 LoRA 参照 → `t500`/`t850`=Turbo LoRA ckpt 版本）
4. **步数**（两位补零：04 → 06 → 08 → 14 → 16）

对比图：`cmp_{主题}_{分辨率}_{时刻}.png`
